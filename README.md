# arnaucanet.github.io

Portfolio personal de Arnau Canet Català, desarrollador backend e integración de IA.

Hecho con [Astro](https://astro.build), Vue.js y Tailwind CSS. Se publica automáticamente en GitHub Pages con cada push a `main`.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build
```
